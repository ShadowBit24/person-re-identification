# Person Re-Identification System

M.Sc. project, Lakehead University.

## Overview

A computer-vision system that re-identifies a person across different camera views — matching images of the same individual despite changes in viewpoint, lighting, and pose.

## What I did

- Built the model in Python using deep-learning frameworks
- Trained and evaluated the system with a documented testing methodology
- Measured and documented system performance

## Skills demonstrated

Python · deep learning · computer vision · model evaluation & testing methodology

## Repository note

This repository holds the project documentation. The original source code was kept on a university lab machine and is not preserved; the design and results are documented here.
